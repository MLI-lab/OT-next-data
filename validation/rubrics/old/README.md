# Historical examples and results

`labeled_examples/` contains the original calibration labels, source evidence,
task snapshots, collected results and dataset-specific provenance utilities.
It was moved here on 2026-10-30 after the old calibration workflow was retired
at the user's request. There is no duplicate at the previous top-level path.

The obsolete `scripts/stage5_calibration.py` tool was deleted. These records
are preserved for reference and are not part of the new 80-task experiment.
